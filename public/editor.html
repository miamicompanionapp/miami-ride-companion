The API key is stored securely as a Cloudflare environment variable — not in the browser. To set it up: go to Cloudflare Dashboard → Pages → miami-ride-companion → Settings → Environment Variables → Add variable, set key name ANTHROPIC_API_KEY and paste your key from console.anthropic.com.
