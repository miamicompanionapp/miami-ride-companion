Design notes
Word list: Miami proper nouns + slang (GROVE, DORAL, WYNWD, BORAL, LUMMUS, etc.) — 5-letter answers only; clue is in the active language but answer stays English.
Color legend: green = correct position · gold = right letter wrong spot · grey = not in word.
One puzzle per day (date-seeded index into word list). "Day 182" counter replaces a calendar.
Streak + personal best stored in localStorage, shown in header chips.
Accent color for border-top: #F97316 (warm orange — distinct from all existing game cards).
