Design notes
Dots are gold (#E5C06B). Unclaimed edges shown as dashed dim lines; tapping them draws a solid colored line in the active player's color.
Completing a box fills it with a translucent player color + initials. Completing a box grants another turn (standard rules).
Grid size: 4×4 boxes (5×5 dots). Fits comfortably on the tablet at ~260px. Could allow 3×3 for faster games — defer to user feedback.
Tap hit-targets: edge midpoints get large invisible tap areas (~44px) so fat fingers hit reliably.
Accent color for card border-top: #22D3EE (cyan — lighter than the existing teal #19A0A8 to differentiate).
