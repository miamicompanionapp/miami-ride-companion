Design notes
Uses multi-touch events (touchstart). Each unique touch point gets a colored dot. Colors cycle: teal → pink → purple → gold → orange → green (up to 5 simultaneous touches on most tablets).
3-second countdown starts when ≥2 fingers are detected. Any finger lifting before the 3s is up resets the countdown (prevents early lift-and-cheat).
Chosen finger: random index among all live touch points at countdown end. The chosen dot animates (scale pulse + glow + radial shimmer). All others dim.
No "player names" needed — colors are the identity. Result says "Purple is it!" — everyone knows which finger that is.
No back-end, no storage. Pure touch event toy. Estimated ~1 hour to build.
Accent color for card border-top: #C084FC (lavender-purple — same purple family as the image game's #7C3AED but lighter/distinct).
This is a utility, not really a "game" — could be labeled as a Bonus or Quick-Play card in the grid to set expectations.
